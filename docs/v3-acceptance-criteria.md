# Navigator v3 — 验收标准 (Acceptance Criteria)

> 每项功能必须满足以下标准方可视为完成。验收分三个等级：**P0**（必须通过才能发布）、**P1**（重要功能，通过后发布）、**P2**（美化，影响体验但非阻塞）。

---

### 1.1 模糊搜索
| # | 验收标准 | 测试方法 |
|---|---------|---------|

## 验收评级

| 等级 | 含义 | 对发布的影响 |
|------|------|-------------|
| ✅ Pass | 完全满足标准 | 可发布 |
| ⚠️ Minor | 小瑕疵，不影响功能 | 可发布，下一版本修复 |
| ❌ Fail | 不满足标准 | 阻塞发布，必须修复 |

### 发布 Gate

所有 P0 验收项必须 **✅ Pass**，P1 最多允许 **2 个 ⚠️ Minor**，P2 无条件限制。
