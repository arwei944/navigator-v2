# 管理后台体验：登录页布局 · 免登录 · 版本标识 · 关于页

四条来自实际使用的反馈。其中一条（"密钥自动填入、直接进后台"）踩到了安全红线，
**没有照字面做**，而是换成了三种同样达到目的、且不泄露密钥的做法。

---

## 0. 四条需求与处理

| 反馈 | 处理 |
|---|---|
| 页面没有自适应屏幕 | 登录卡片改**垂直+水平居中**（原先被 flex 默认 stretch 拉满整屏） |
| 密钥自动填入、直接跳转后台 | **换方案**：本机自动登录 + 会话持久化 + 口令登录（见 §2） |
| 页面要有明显的版本标识 | 登录页底部 + 后台 header 都显示版本徽标 |
| 新增关于项目的页面 | `/about`，侧边栏入口，含版本 / 功能 / 技术 / 后台安全说明 |

## 1. 登录页为什么看着"不对"

`AdminLogin.vue` 的容器只有 `justify-content: center`，**没有 `align-items`** ——
flex 默认 `stretch` 会把卡片高度拉到与容器等高。于是内容只占卡片上半截，
远看就是「卡片贴顶、下方一大片空白」，而且窗口越高越明显。

修法：加 `align-items: center`，并让窄屏（≤520px）卡片吃满可用宽度、内边距收窄。
父级 `.admin-body` 本来就是 `flex:1`，高度确定，居中不需要额外的 `min-height` 技巧。

## 2. 免登录：为什么不能把密钥写进前端

**把 `SITES_ADMIN_KEY` 硬编码进前端，等于公开发布永久管理密钥。**
前端产物是公开可下载的，没有"藏起来"这种可能 —— 任何人按 F12 就能拿到它，
然后完整控制后台（增删站点、改插件配置、发布数据）。

项目此前为此专门改过设计：`opsApi.js` 与 `AdminLogin.vue` 里都有长注释说明
「共享密钥不再进浏览器，登录改为签发有期限、可轮换的会话 token」。
照字面实现会把这条线推翻，所以换成下面三条**可叠加**的做法。

### 2.1 本机自动登录（新增）

密钥**留在服务端**，只在「确认是本机访问」时才吐给页面。新增 `api/_local-key.js`：

```
① 连接来源是回环（127.0.0.1 / ::1 / ::ffff:127.0.0.1）
② 且 请求 Host 也是回环（127.0.0.1 / localhost / [::1]）
```

**为什么必须两个条件**：反向代理（包括托管平台）转发过来的请求，源地址可能是内网甚至回环，
只查 `remoteAddress` 会让线上也判成「本机」。加上 Host 校验后，
线上一律命中第 ① 或第 ② 条的否定分支 → **返回 404**（不是 403：
403 等于告诉对方「这里有个东西但不给你」）。

前端在 `location.hostname` 属于回环时才尝试这个端点，成功即直接进后台、
连表单都不闪。后台会如实标注「本机自动登录」，不假装是人工登录。

### 2.2 会话持久化（改动既有行为）

token 从 `sessionStorage` 改存 `localStorage`。原先关掉标签页就得重登，
**服务端签了 90 天的 token，客户端却存不过一次关标签页 —— 这个承诺是假的**。

代价如实记录：暴露窗口从「一次标签页」变成「直到过期」。缓解手段是
`getAdminKey()` 每次读取都校验 exp、过期就地清除，退出登录立即删除。
旧位置（sessionStorage）读到即迁移，避免两处不一致。

### 2.3 口令登录（机制已就绪，配一次即可）

比密钥安全：有期限、可轮换、密钥不进浏览器。服务端侧的回填机制**本来就有**
（`server/main.mjs` 读 `data/admin-password-hash.txt`），`AUTH_SECRET` 可回退到 `SITES_ADMIN_KEY`。

为了让"配一次"不必手工拼 Files API，新增一条命令：

```bash
npm run auth:password -- --upload
```

交互式输入口令（不回显、不进 shell 历史）→ 生成 scrypt 哈希 → 写本地文件 →
上传到线上容器 → 重启。之后用「用户名 + 口令」登录并勾「记住此设备」，
按服务端 90 天期限免登录。

## 3. 版本标识

数据来自已存在的公开只读接口 `/api/deploy-status`（含 `shortSha` / `branch` / `dirty` / `builtAt` / `subject`）。

- 后台 header：标题右侧一个版本徽标，悬停显示分支 / 提交说明 / 构建时间；
- 登录页：卡片底部一行「版本 xxxxx」。

两处都**读不到就不显示**，绝不编一个假的 —— 版本号编错比不显示更糟。

## 4. 关于页

`/about`，套壳（带侧边栏），懒加载（`defineAsyncComponent`），侧边栏在「管理后台」下方加一项。

内容四块：**版本**（真实构建信息 + 站点数 + 数据版本 + 运行时）、
**它做什么**（七条功能）、**技术构成**、**管理后台与登录**（把三条路径与安全边界讲清楚）。

最后那块是有意放的：用户问"为什么不自动填密钥"时，答案应该能在产品里直接读到，
而不是散在代码注释里。

## 5. 验收

| 项 | 证据 |
|---|---|
| 闸门单测 | `test-local-key.mjs` **14 条** —— 核心是「回环 IP + 线上域名 → 拒绝」 |
| 真机（三项 UX） | `probe/admin-ux-verify.mjs` **22 条**：登录页居中（上下留白 243/243）、自动登录、版本标识、关于页 |
| 全量回归 | `console:test:all` **53 脚本 exit 0** |

真机探针分两轮是有意的：自动登录成功后看不到登录页，所以第一轮用 CDP
在文档加载前把 `/api/_local-key` 打成 404，才验得到登录页的布局。

**逮到的缺陷**：关于页正文里我写了 markdown 的 `**粗体**`，Vue 不解析它 ——
字面星号直接显示在页面上。真机截图才看出来，已改成 `<b>`。

## 6. 不做的事

- **不把密钥写进前端**（见 §2 的理由）；
- **不做"访问 /admin 即免登录"的线上自动登录** —— 那要求密钥或长期凭据在无人工确认的情况下
  自动加载，与「凭据不进浏览器」冲突。想线上免输，走 §2.3 的口令登录；
- **不在关于页堆技术细节** —— 它回答「这是什么、跑的是哪版、怎么进后台」，不是架构文档。
