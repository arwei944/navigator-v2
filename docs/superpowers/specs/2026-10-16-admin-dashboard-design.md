# 管理后台 · 卡片仪表盘 —— 设计文档

日期：2026-10-16
范围：管理后台中间区（`src/views/AdminView.vue`）
决策来源：在 20 种布局决策页里，用户先选 L01（顶部标签），我按「在它基础上升级完善」保留了骨架；
上线后用户反馈「管理后台布局还是没有更改」——**骨架没换，所以看不出来**。
这一轮明确选了 **⑥ 卡片仪表盘**。

---

## 0. 需求

中间区不再是「一排 tab + 单面板」，而是**铺满的模块卡片**。

## 1. 为什么上一轮「看不出变化」

L01 就是「现状基线」，我把它理解成「保留骨架、补掉已知代价」，于是只改了三处**细节**：
分组分隔线、装不下时收进「更多」、键盘 ←/→。

更糟的是：**在用户的窗口宽度下（约 1930px）13 个 tab 全能塞下，「更多」根本不出现** ——
本次升级里最实质的那一项，在他屏幕上天然不可见。可见的只剩几条细分隔线。

教训记在这里：**用户说「升级完善」时，先问清楚「你期望看到什么变化」**，
不要默认他会满足于「代价被补掉但样子没变」。这次是问了之后才对齐的。

## 2. 方案

### 2.1 仪表盘 = 原「概览」面板，不是新增一页

| 组成 | 来源 |
|---|---|
| 4 个 KPI（站点 / 分类 / 今日访问 / 收藏） | 原概览面板，原样保留 |
| 12 张模块卡片 | 新增 |
| 数据洞察（分类分布 / 点击量 TOP10） | 原概览面板里的 `AdminInsights`，原样保留 |

理由：不新增页面、不丢任何现有内容，只是把「概览」重排成「一屏看到所有模块」。
tab 行的第一个入口因此改名为**「仪表盘」**（id 仍是 `overview`，快捷键与深链接不受影响）。

### 2.2 仪表盘上收起 tab 行

卡片本身就是导航，所以仪表盘上不渲染 `.admin-tabbar`；**进模块后 tab 行出现**，
承担「切模块 / 返回仪表盘」。这样「不再是 一排 tab + 单面板」是**看得见**的，
而不是「下面换了张图，上面那条 tab 还在」。

### 2.3 卡片铺满：`auto-fill` 而不是固定列数

```css
grid-template-columns: repeat(auto-fill, minmax(230px, 1fr));
```

中间区宽度会随两侧栏折叠、窗口缩放变化（三栏壳下 900px～1400px 都可能），
**固定列数必然在某档宽度下留出大片空白** —— 这正是「布局不自适应」的来源。
卡片用 flex 列 + `margin-top:auto` 让「数字」和「进入 →」在任何高度下都对齐底部。

### 2.4 卡片上的数字：拿不到就不写

只放**页面上已经拿得到**的：站点数、分类数、部署版本、云端版本、通知未读数。
其余 7 个模块**只给一句话说明、不给数字** —— 宁可不显示，也不编一个好看的数
（这是本项目反复强调的口径，也是我在 20 布局决策页里犯过的错的教训）。

## 3. 验收

| 项 | 方式 | 结果 |
|---|---|---|
| 仪表盘渲染 | `probe/admin-tabnav-verify.mjs`（真机，含线上） | 12 张卡 / tab 行不渲染 / 网格占内容宽 ≥95% / 每行 ≥3 张 / 无 `undefined`·`NaN` |
| 点卡片进模块、再回仪表盘 | 同上 | 进「插件」→ `?tab=plugins` + tab 行出现；点「仪表盘」→ 回到卡片页 |
| **重复标题守卫** | 同上 | 仪表盘内 h2/h3 文案不许重复（本项目被「渲两遍」咬过两次） |
| 导航升级（分组 / 更多 / 键盘） | 同上，全部在模块页里复验 | 22 条 |
| 无回归 | `console:test:all` | 62 个脚本 |

**探针自身要改**：原来它启动后就等 `.admin-tabs`，而仪表盘上 tab 行不存在 ——
这会让一支好探针变成「一启动就失败」。改成等 `.admin-view`，
并在仪表盘断言之后再点卡片进模块，导航断言全部挪到模块页里做。

**截图逮到的缺陷**：初版我在 `AdminInsights` 上方又加了一个「数据洞察」标题，
而该组件自带同名标题 → 页面上出现两个「数据洞察」。已删掉我加的那个，
并补了「仪表盘内标题不许重复」的断言。

## 4. 不做的事

- **不改 13 个面板的内部布局**：本次只动中间区的组织方式，面板组件一行未改。
- **不做卡片自定义排序 / 隐藏**：那是用户偏好持久化，另一件事。
- **不给卡片加缩略图 / 图表**：卡片负责「这是干什么的 + 一眼状态」，进去才看细节。
- **不删任何现有内容**：KPI 与数据洞察都留着，只是重新排布。
