    选择文件查看 diff
    
        
    
      
    
      
    
        diff 按 hunk 分块展示，每块右侧可「暂存此块 / 取消暂存此块」——只搬选中的块，其余块留在原侧，
        等价于终端的 git add -p 而不必离开控制台。部分暂存的文件会同时出现在「已暂存」与「未暂存」两侧，
        分别对应索引侧与工作区侧的差异。二进制、未跟踪文件以及超出展示上限的差异不支持分块。
